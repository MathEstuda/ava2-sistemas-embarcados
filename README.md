# AVA2 - Sistemas Embarcados

## Monitoramento da luminosidade com sensor LDR

Projeto desenvolvido para a disciplina de Sistemas Embarcados da Universidade Veiga de Almeida.

O sistema utiliza um módulo sensor LDR e uma placa STM32 Nucleo C031C6 para monitorar a intensidade luminosa.

Conforme o nível de iluminação identificado, o sistema aciona um dos seguintes LEDs:

- LED vermelho: baixa luminosidade;
- LED amarelo: luminosidade intermediária;
- LED verde: alta luminosidade.

## Componentes utilizados

- STM32 Nucleo C031C6;
- módulo sensor LDR;
- LED vermelho;
- LED amarelo;
- LED verde;
- resistor;
- fios de conexão;
- simulador Wokwi.

## Resultados

Durante a simulação, foram observados os seguintes resultados:

- 9 lux: LED vermelho;
- 200 lux: LED amarelo;
- 2884 lux: LED verde.
